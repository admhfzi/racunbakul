# racunbakul writing style (for every thread / caption)

- all lowercase, no capital letters at all (including brand names, start of sentences)
- no emoji
- casual chat tone, like talking to friends: "aku", "korang", "weh", "tau", "je", "la", "kot"
- short sentences, easy to understand, no heavy promo language
- product facts only from the label/listing; health claims are not promised ("hasil lain-lain orang")
- no teacher/school/lecture context
- the story is a draft, the user changes it to their real experience
