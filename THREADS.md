# Thread scripts (TikTok text slides / voiceover)

Format: one short line per slide (or one line per sentence of voiceover), 6–8 slides.
Structure: Hook → Problem → Discovery → Features (from the label only) → Close + CTA.
⚠️ The stories are drafts. Change them to match your real experience so they don't mislead buyers.

## Tips
- Slide 1 (the hook) appears big in the middle top for 1–2 seconds; each following slide 1.5–2 seconds.
- Use a different font/colour for the product name so the eye stops on it.
- For voiceover: read slowly, in a "telling a friend" tone, not an advertisement tone.
- Turn on the "AI-generated content" label if the video uses AI footage.
